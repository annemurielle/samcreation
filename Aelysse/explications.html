Comment lire le manga ?

Le lecteur permet de passer d’une planche à l’autre avec les boutons Précédente et Suivante. Le menu propose toutes les pages et les chapitres. Sur ordinateur, vous pouvez également utiliser les flèches du clavier.

Voir les illustrations en grand

Touchez une image dans une galerie pour l’agrandir. Les boutons permettent de parcourir les dessins, de zoomer ou d’ouvrir l’image seule. La touche Échap ferme la vue agrandie.
